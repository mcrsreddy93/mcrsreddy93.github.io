🧪 Playwright test hints — handling dialogs

✅ Use page.on('dialog') or page.waitForEvent('dialog').
✅ Accept / dismiss / type text into prompt.
✅ Example snippet:

// Accept alert
page.once('dialog', dialog => dialog.accept());
await page.click('#alertBtn');

// Confirm with accept/reject
page.once('dialog', dialog => dialog.accept());
// Or dialog.dismiss();

// Prompt: accept with text
page.once('dialog', dialog => dialog.accept('my text'));
await page.click('#promptBtn');

⭐ All dialogs on this page are native browser dialogs — fully compatible with Playwright's Dialog methods.
